# UART 帧协议规范（K210 视觉端 → STM32）

版本：v1 ｜ 波特率 115200，8N1 ｜ 实现：`protocol/frame_parser.c`（逐字节状态机）

## 帧格式

```
偏移  字段      长度    说明
0     帧头      2       固定 AA 55
2     N         1       目标个数，合法范围 1..8（0 非法，拒收）
3     cls[N]    N       目标类别：1=火焰，2=烟雾
3+N   conf[N]   N       置信度 0..100（整数量化）
3+2N  chk       1       校验 = (N + Σcls + Σconf) & 0xFF（累加和）
4+2N  帧尾      2       固定 55 AA
```

最短帧长 7 字节（N=1），最长 21 字节（N=8）。

## 字节流示例

单目标（烟雾 cls=2，置信度 85），由 `tools/fake_vision_sender.py` 生成：

```
AA 55 01 02 55 58 55 AA
       │  │  │  │
       │  │  │  └ chk = (01 + 02 + 55) & 0xFF = 0x58
       │  │  └ conf[0] = 0x55 (85)
       │  └ cls[0] = 0x02 (烟雾)
       └ N = 0x01
```

双目标（火焰 85 + 烟雾 65）：

```
AA 55 02 01 02 55 41 9B 55 AA   → chk = (02+01+02+55+41) & 0xFF = 0x9B
```

Python 端为协议参考实现，`tools/stdin_parse.c` 用于跨语言交叉验证
（Python 编码 → C 解码，结果必须一致）。

## 同步与容错规则

1. **逐字节状态机**：不依赖 DMA/IDLE 边界，任何字节流切分方式下行为一致
2. **帧头回退**：状态机收到 `AA` 后期待 `55`；若下一字节仍是 `AA`，退回"已收帧头1"状态而非从头开始——连续背靠背帧场景下不丢帧
3. **拒收条件**（统一回帧头搜索状态）：
   - 校验和不匹配
   - N = 0 或 N > 8
   - cls ∉ {1, 2}（可选严格模式）
4. **前导垃圾**：帧头前的任意垃圾字节自动跳过

## 演进方向

- 校验升级 CRC8/CRC16：只改 `vp_checksum()`，收发两侧同步
- 视觉结果帧扩展（如增加 bbox 坐标）：追加变长字段时保持帧头/帧尾/校验布局不变
